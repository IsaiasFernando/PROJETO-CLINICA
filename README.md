# Desafio b2bflow - Python + Supabase + Z-API

Projeto em Python que lê contatos cadastrados no Supabase e envia, via Z-API, a mensagem:

```text
Olá, <nome_contato> tudo bem com você?
```

O envio é limitado a até 3 contatos por execução.

## Setup da tabela no Supabase

Crie uma tabela chamada `contacts` com os campos `name` e `phone`:

```sql
create table contacts (
  id bigint generated by default as identity primary key,
  name text not null,
  phone text not null,
  created_at timestamp with time zone default now()
);
```

Exemplo de registros:

```sql
insert into contacts (name, phone) values
  ('Marcelo', '5511999999999'),
  ('Ana', '5511888888888'),
  ('João', '5511777777777');
```

Use telefones com DDI e DDD. Exemplo para Brasil: `55` + DDD + número.

## Variáveis de ambiente

Copie o arquivo `.env.example` para `.env` e preencha:

```env
SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_KEY=sua-chave-anon-ou-service-role

CONTACTS_TABLE=contacts
NAME_COLUMN=name
PHONE_COLUMN=phone
SEND_LIMIT=3

ZAPI_INSTANCE_ID=sua-instancia
ZAPI_TOKEN=seu-token-da-instancia
ZAPI_CLIENT_TOKEN=seu-client-token

DRY_RUN=false
```

Para testar sem enviar mensagens reais, use:

```env
DRY_RUN=true
```

## Como rodar

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python main.py
```

## Observações

- O código busca contatos do Supabase e envia no máximo 3 mensagens.
- A mensagem enviada segue o formato exato: `Olá, <nome_contato> tudo bem com você?`.
- Contatos sem nome ou telefone são ignorados e registrados no log.
